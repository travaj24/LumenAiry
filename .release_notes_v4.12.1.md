### `trace_jax` jit cache — root cause was a JAX bug

v4.12.0 reverted the `trace_jax` jit cache because `jax.grad(fit_canonical_polynomials_jax)` returned **NaN**. The hypothesized cause was the flat-tuple cache key losing gradient flow through the prescription. The agent investigating found this was wrong — the actual cause is a JAX bug: `jax.jit` wrapping `trace_jax` + downstream `jnp.linalg.lstsq` backward produces NaN in `dot_general` for near-rank-deficient matrices (the canonical-poly 4-D Chebyshev basis triggers it).

v4.12.1 ships a hybrid implementation:
- **Concrete-leaves path** (the normal case): `JaxPrescription` pytree wrapper registered via `jax.tree_util.register_pytree_node`. Numeric leaves (radii, conics, thicknesses, asph coeffs) flow as pytree leaves; categorical aux (glass names, surface flags, asph powers) forms a hashable cache key. Compiled kernel cached in `_TRACE_JAX_CACHE`.
- **Tracer path** (under `jax.grad` / `jax.jit` / `jax.vmap`): `_running_under_trace` guard detects when any leaf is a `jax.core.Tracer` and bypasses the jit-cache layer entirely. The calling transform already owns the trace; the extra `jax.jit` wrap is redundant *and* triggers the lstsq bug. Bypassing preserves v4.11.2 grad semantics.

**The critical pin**: `jax.grad through fit_canonical_polynomials_jax is finite -- grad=1.0274e+04` (was `grad=NaN` in v4.12.0).

### Raytrace Newton spherical fast-path — conservative-numerics version

v4.12.0 reverted the spherical fast-path because the **analytic spherical normal** `(x/R, y/R, (z-R)/R)` compounded a 1.17e-3 NumPy↔JAX drift through the Maslov asymptotic chain — failing the `aberration_tensor_lg00_jax matches NumPy` validation pin.

v4.12.1 keeps **only the Newton skip** (the main cost saving) and reverts to the legacy numerical-radial-derivative-based `_surface_normal` in `_refract`/`_reflect` so LSB rounding is bit-identical to v4.11.2. The fast-path applies when `conic == 0 AND not aspheric_coeffs AND radius_y is None AND freeform is None AND finite(radius)` — any non-spherical feature falls back to Newton.

**The critical pin**: `aberration_tensor_lg00_jax matches NumPy (0,0) element -- rel_err=4.53e-04` (was 1.17e-3 broken; 4.83e-4 v4.11.2 baseline — actually slightly better than baseline).

Smaller speedup (1.50× vs the 1.64× v4.12.0 attempted), but the cross-backend correctness pin holds. The remaining ~0.14× from the analytic-normal change is permanently sacrificed for the cross-backend rounding stability — the right trade per the discipline lesson from C-LR-1.

### `JaxPrescription` exported

```python
from lumenairy.raytrace.jax_trace import JaxPrescription, trace_jax
jp = JaxPrescription.from_prescription(prescription, wavelength)
# first call: ~127 ms (trace + compile + cache)
out = trace_jax(state, jp, wavelength)
# every subsequent call with the same JaxPrescription: ~0.4 ms
```
