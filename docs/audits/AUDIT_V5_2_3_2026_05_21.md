### P2 — should fix soon

**P2-F1-1 — HFPI/HF freespace dispatcher silently drops `output_grid`/`output_dx`**
File: `dispatch.py:584-594` (hfpi) and `:611-617` (hf). After the v5.2.3 P1-A residual fix added `_resolve_dispatcher_output_grid` to the `through_prescription` paths, the **freespace** branches (when `prescription is None`) still drop the resolved values. `propagate_hfpi_freespace_aperture` accepts `output_shape`/`output_grid`/`output_dx` but the dispatcher never threads them through. Calling `la.propagate(method='hfpi', output_grid=(N_out, dx_out))` without a prescription silently produces a default-shape result.

**P2-F1-2 — V12 walker regex misses short-form audit IDs**
File: `test_v5_2_walker_changelog_changeset.py:104-105`. The regex `r'(?<![A-Z0-9])(P[0-3](?:-NEW)?-[A-Z][A-Z0-9_-]{2,})'` requires `[A-Z0-9_-]{2,}` after the first uppercase letter. The v5.2.3 CHANGELOG cites `P1-A`, `P1-C`, `P1-F`, `P1-G`, `P1-1` — **all rejected by the regex**. V12.2 therefore skips with "No audit IDs cited"; the structural CHANGELOG-vs-audit-doc check is a no-op on the current release. A fabricated short-form ID like `P1-X` would silently pass.
**Fix**: relax to `r'(?<![A-Z0-9])(P[0-3](?:-NEW)?-[A-Z0-9][A-Z0-9_-]*)'` and add a known-prefix allowlist to clamp false positives.

**P2-F1-3 — V16 walker silently skips on v5.2.3's actual CHANGELOG**
Files: `scripts/verify_changelog_closures.py:159-179` (heading classifier) and `test_v5_2_3_walker_changelog_content.py:113-120` (skip on rc=2). `_is_audit_closure_section` only matches headings containing `'audit closure'`, `'audit carry-over'`, `'audit fix'`, or `\bp[0-3]\s+closure`. The v5.2.3 CHANGELOG uses `"Tier 1 closures"`, `"Tier 2 closures"`, `"Tier 3 closures"` — **none match**. The CI gate at `publish.yml:73-82` treats rc=2 as pass, so a v5.2.4 with fabricated `### Tier N closures` bullets would not be caught.
**Fix**: extend `_is_audit_closure_section` to match `'tier ' + digit + ' closure'`.

**P2-F1-4 — publish.yml verify matrix missing Python 3.10**
