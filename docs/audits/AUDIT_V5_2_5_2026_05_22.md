## Part 6 — F1: Fresh-eyes findings (1 P1 + 2 P2 + 9 P3)

### P1 — BLOCKER

#### **P1-1: HF freespace dispatcher fix is BROKEN (TypeError regression)**

**Files:** `lumenairy/propagators/dispatch.py:624-635` + `lumenairy/propagators/hf.py:88-107`

The v5.2.5 P2-F1-1 closure threads `output_shape`/`output_dx` through `propagate_huygens_fresnel_freespace`, but that function is a thin wrapper around `rayleigh_sommerfeld_propagate` (rs.py:36, signature `(E_in, z, wavelength, dx, dy, bandlimit, use_gpu, verbose)`) which does **not** accept `output_shape` or `output_dx`. Both `output_grid` AND `output_dx` paths fail.

Reproducer:
```python
la.propagate(np.ones((64,64),dtype=complex), z=0.01, wavelength=633e-9, dx=10e-6,
             method='hf', output_grid=(64, 10e-6))
# TypeError: rayleigh_sommerfeld_propagate() got an unexpected keyword argument 'output_shape'
```

The same call with `output_dx=10e-6` alone (no `output_grid`) also fails because `_resolve_dispatcher_output_grid` always returns a square shape when either kwarg is non-None.

**Pre-v5.2.5 behavior**: silent no-op (the kwargs were dropped) — the user got default shape but no error.
**v5.2.5 behavior**: hard `TypeError` — any caller that was setting `output_grid` (and tolerating the no-op) now crashes.

**Severity:** This is a hard regression. Library callers who used `method='hf'` with `output_grid=...` (the dispatcher's documented canonical API) no longer work. HFPI works correctly because its receiver natively accepts those kwargs; only HF is broken.

**No regression test exists for this fix** — neither the dispatcher-level nor the HF-side accept-the-kwargs side is pinned in `tests/`. This is exactly the "fix has no test" anti-pattern.

**Fix options:**
- (a) `propagate_huygens_fresnel_freespace` drops `output_shape`/`output_dx` from `**kwargs` before forwarding to `rayleigh_sommerfeld_propagate`, then handles resampling itself
- (b) The dispatcher branch at `dispatch.py:628-632` should NOT call this function with those kwargs (more honest given the function's RS-pass-through nature) — instead, emit a `UserWarning` documenting that HF freespace doesn't support resampling
- (c) Both: keep the dispatcher resolver but only pass the kwargs when the receiver supports them
