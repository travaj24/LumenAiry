## Part 7 — F1-C: Edge-case findings (3 P2 + multiple P3)

### P2 — Sellmeier edge cases (NEW)

**P2-1: Negative wavelengths silent symmetry** (`coatings.py:486`)
```python
n(-500nm) == n(+500nm)  # exact equality
```
The `lam2 = (wl*1e6)**2` makes the formula sign-symmetric. Range warning fires (because `wl < lmin`), but the returned value is plausible — a negative wavelength in an array silently lands in the documented band. **Fix**: `if np.any(wl_arr < 0): raise ValueError` OR rectify to `lam2 = abs(wl)**2 * 1e12` and document.

**P2-2: NaN wavelengths return NaN with NO warning** (`coatings.py:547`)
The check `np.any(wl_arr < lmin) or np.any(wl_arr > lmax)` returns `False` for NaN comparisons (IEEE 754). A single NaN in an array yields NaN at that slot silently. **Fix**: add `if np.any(np.isnan(wl_arr)): warn(...)`.

**P2-3: SiO2 registry range exceeds Malitson 1965 validity** (`coatings.py:391`)
- Registry: `range=(200e-9, 8000e-9)`
- Source comment: "Malitson 1965 valid 0.21-6.7 µm"
- At λ=7.5µm: **n = 0.945** (non-physical, n<1 for dielectric in air)
- At λ=8.0µm (registry's `lmax`!): **n = 0.642**
- Range warning does NOT fire at exactly `lmax` because check is strict `>`
- **Fix**: tighten to `(200e-9, 6700e-9)` per source citation
