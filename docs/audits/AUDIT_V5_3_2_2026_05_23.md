## Part 6 — F1+F3+V1: HF freespace Parseval renorm gap (NEW P2, CONVERGENT)

**Three independent agents (V1, F3, F1) flagged the same finding:**

The v5.3.0 P1 closure (HF freespace TypeError fix) is missing the Parseval renormalization step that the CHANGELOG explicitly claims it inherits from the MHS pattern.

**The claim** (`CHANGELOG.md:253-254`): The fix "matches the v5.2.3 MHS substantive-resampling pattern at `mhs.py:573-611`."

**The MHS pattern has TWO components:**
1. Native-kernel call + `resample_field` bridge — ✓ HF has this
2. `sqrt(p_in/p_out)` Parseval renormalization at `mhs.py:602-606` — ✗ **HF doesn't have this**

**Empirical Parseval test (F3)**:
| Case | rel_err |
|---|---|
| Same N+dx (identity resample) | 4.9e-16 (bit-exact) |
| Downsample N=256→128 well-confined | 0 |
| Upsample N=256→512 well-confined | 2.4e-7 (interp noise) |
| **Edge-grazing Gaussian (w0=25·dx) upsample** | **1.6% power drift** |

**Test pin is too loose to catch this** (F1): `test_hf_freespace_resampled_power_is_preserved` uses `0.5 < ratio < 2.0` — 100% tolerance, not the 1e-9 Parseval pin MHS uses. The test's own comment acknowledges: "Pin to within 20%... the test is a sanity guard against catastrophic amplification, not a Parseval pin."

**Second sub-finding** (F1): No same-shape/same-dx short-circuit. MHS at `mhs.py:583-587` skips `resample_field` when input shape AND dx already match the target. The HF wrapper unconditionally calls `resample_field` whenever either kwarg is non-None, doing unnecessary identity-resample work (two `map_coordinates` passes with `mode='constant', cval=0.0` that attenuate edge-pixel power).

**Severity:** P2 (not P1) because:
- Well-confined fields (typical optical workloads) see sub-ppm drift
- Edge-grazing fields are uncommon in practice
- No CRASH — just silent power drift
- TypeError fix itself (the P1 closure) works correctly

**Fix options:**
- (a) Add `sqrt(p_in/p_out)` renormalization to match the cited MHS pattern (1 line of code)
- (b) Add the same-shape/same-dx short-circuit
- (c) Tighten the test pin to `(0.99, 1.01)` (1% tolerance) on well-confined Gaussians, or to a Parseval rel_err < 1e-3 pin
- (d) Soften the CHANGELOG claim from "matches the MHS pattern" to "uses the same `resample_field` step but without renormalization"
