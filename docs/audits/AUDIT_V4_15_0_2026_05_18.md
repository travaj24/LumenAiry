## TL;DR

**v4.14.3 closure is CLEAN.** All 2 P0 + 14 P1 findings from the v4.14.2 audit closed with strong dispatcher/sentinel patterns. The "fix N, miss N+1" meta-pattern is structurally broken in v4.14.3 (fixes are dispatcher/single-canonical-site, not N parallel sites). V5 verified 1265 unit tests pass.

**v4.15.0 ships major-scope additions** — modal-asymptotic 19.4× perf with batched cold-start, 7 new public API functions, 3 new partial-coherence source factories, Forbes Q-bfs/Q-con freeform basis, off-axis parabola factory, `lumenairy.evaluate()` ergonomic entry, third structural meta-pin. 1425 tests pass (up from 1265).

**However, this is the highest-yield audit in the series:** 2 confirmed P0s + 12 P1s — most in NEW v4.15.0 code. The release ships fast, with property-only test pins that miss analytical-value verification, and the meta-pattern "fix N, miss N+1" recurs **6 distinct times** on v4.15.0 itself.

**Headline P0/P1 findings (sorted by severity):**

1. **🔴 P0-NEW-1: `make_off_axis_parabola` is functionally broken** — decenter formula off by 2× (`r = f·tan(θ)` should be `2f·tan(θ)`), tilt stored as 3-tuple but `apply_real_lens` reads as 2-tuple small-angle linear ramp (27% error at 45° fold). **2-way confirmed (V4 + F1).** No end-to-end raytrace test catches either bug.

2. **🔴 P0-NEW-2: Schell-family partial-coherence factories are unfulfillable** — all 3 (`create_gaussian_schell_source`, `create_schell_model_source`, `create_annular_incoherent_source`) collapse their `n_realizations` ensemble into a SINGLE deterministic complex field before return. The returned object is fully coherent; the documented MCF / Schell theorem / vCZ contract is unfulfillable. **2-way confirmed (V3 under-pinned + F3 mechanism-traced + F1 mathematically broken even at MCF level).** Plus the random-phase recipe gives wrong functional form (`<exp(iΔφ)> = exp(-(1-ρ(Δr)))`, not documented Gaussian kernel).

3. **🔴 P1-NEW-A: `sparrow_resolution` returns 15% below canonical Sparrow on clean Airy** — implementation doubles the single-PSF inflection point, not the two-source dip-vanishing condition. Empirical: returned 1.93 µm vs expected 2.27 µm for λ=600nm,f/#=4. Test pins only `< rayleigh`, not analytical value. (V3)

4. **🔴 P1-NEW-B: Modal-asymptotic "physics fix" is SELF-CONSISTENT-ONLY** — v4.15.0's headline replaces known-buggy warm-start with UNVERIFIED cold-start. No Hessian PD check; no multi-start fallback; **no independent ground-truth test** (audit's #1 recommendation deferred). 4 migrated property pins compare batched-vs-scalar of the SAME cold-start algorithm — catches implementation bugs only. 5 downstream callers inherit bit-different output without new pins. (V2)

5. **🔴 P1-NEW-C: UI subpackage emits its OWN `DeprecationWarning`s** — 7 callsites in `ui/model.py` use legacy positional Source factory form. The v4.15.0 release that introduced the deprecation shim didn't migrate its OWN internal UI consumers. (F2)

6. **🔴 P1-NEW-D & E: Forbes Q is half-shipped** — math + dispatcher are correct, but (D) raytrace flat-keys-gather drops `q_bfs_coeffs`/`q_con_coeffs`/`r_max` silently; (E) Zemax `.zmx` loader has no QBFS/QCON parsing. Users must hand-build dict-shape prescriptions to actually use Forbes Q. (F2)

7. **P1-NEW-F: 6 more confirmed bugs from F1** — Q-bfs/Q-con rectangular clip misaligned with radial `r_max`; Forbes dispatcher silent default `r_max=1.0`; `strehl_vector` default plane-wave reference produces Strehl > 1; `rayleigh_resolution` spurious value on Gaussian PSFs; `astigmatism_mag_angle` docstring claims wrong range; `system.evaluate` mixed-shape prescription silent precedence.

**Verdict:** v4.15.0 should **NOT be considered stable** until P0-NEW-1 (`make_off_axis_parabola`) and P0-NEW-2 (Schell factories) are fixed. Both are silent-wrong-physics bugs in CHANGELOG-headlined new features. Plus the 5 modal-asymptotic / Forbes Q / UI deprecation P1s materially affect users who exercise those code paths. **Recommended: v4.15.1 patch closing the 2 P0s + 10 highest-priority P1s.**

**🔴 P0-NEW-3 — Schell phase RMS-normalisation destroys coherence-length physics:**

`sources/core.py:1476-1481` (Gaussian-Schell) and `:1588-1592` (generic Schell):
```python
rms = np.sqrt(np.mean(filtered**2))
if rms > 0:
    filtered = filtered / rms
phase = filtered  # treat as the random phase
```

The phase is normalized to unit RMS REGARDLESS of `sigma_g`. For a Schell-model with `<exp(iΔφ)> = exp(-σ_φ²·(1-c(Δr)))` where σ_φ is the phase variance and `c(Δr)` is the spatial correlation, forcing σ_φ=1 means:
- `sigma_g → 0` (incoherent limit) does NOT recover incoherent — adjacent pixels stay 37% coherent (`exp(-1) ≈ 0.37`)
- `sigma_g → ∞` (coherent limit) doesn't approach coherent until `nr·sigma_g²` is huge

The Schell theorem in the docstring is **not actually honored**. The TestB3SchellSources test only verifies intensity-profile correlation, not the coherence kernel — so the bug passes CI.

### F3 — Forbes math + partial-coherence physics + final-corner

**🔴 P0-NEW-2 (deeper version) — Schell-family factories CANNOT return partial coherence:**

F3 traced the mechanism beyond F1's phase-normalization bug. ALL three factories (`create_gaussian_schell_source`, `create_schell_model_source`, `create_annular_incoherent_source`) compute `intensity_sum`/`coherent_sum` across realizations, then return a **SINGLE** complex field:
```python
E = sqrt(<I>) · exp(i·angle(<E>))
```
The returned single complex field has **fully coherent MCF** `J(r1,r2) = E*(r1)·E(r2)`, NOT the partially-coherent `sqrt(I(r1)I(r2)) · μ(r1-r2)` advertised in the docstring + CHANGELOG.

**Combined with F1's phase-normalization bug, the partial-coherence factories cannot fulfill their documented contract.** A caller using the returned field as a "partial-coherence source" through downstream propagators gets a **fully coherent answer**.

The test pins (`TestB3SchellSources`, `TestB4AnnularIncoherent`) are property-only (intensity envelope correlates, more realizations smooth variance). **No pin verifies the MCF / Schell theorem / vCZ theorem.**

To behave as advertised, the factory would need to return either the (n_realizations, N, N) ensemble OR the (N², N²) MCF matrix — both are larger architectural changes.

**Forbes Q math verified analytically (F3 first-principles check):**
- Derived `c_n² = (2n+α+β+1) · n!Γ(n+α+β+1) / (Γ(n+α+1)Γ(n+β+1))` from A&S 22.2.1
- For Q-bfs (α=β=1): `c_n² = (2n+3)(n+2)/(n+1)` — IMPLEMENTATION CORRECT
- **BUT CHANGELOG line 124-126 AND module docstring** state `c_n = sqrt((2n+3)(n+2)/(n+1)²)` — **wrong power on `(n+1)`** (P3 doc-drift)
- Q-con formula `c_n = sqrt(2n+3)` IS correct
- Orthonormality at 1e-6 verified; no n≥10 stability pin (P3 coverage gap)

The v4.14.3 release was the cleanest in series — small scope, tight discipline. **v4.15.0 is the highest-yield audit since v4.14.1** because it ships large new scope (Forbes Q, partial-coherence sources, modal-asymptotic rewrite, OAP, evaluate, 7 API functions). New surface = new bugs.

### Pattern: Property-only test pins miss algorithm-correctness regressions

v4.15.0's test pins are mostly **property pins** (orderings, shapes, smoothness, monotonicity) rather than **analytical-value pins**. Property pins are necessary but not sufficient:
- `sparrow_resolution`: pinned `< rayleigh` (property), not `≈ 0.947 λ f/#` (analytical) → 15% error silent
- Modal-asymptotic: pinned `nz-count ≥ warm` (property), not vs direct-quadrature (analytical) → cold-start unverified
- Schell factories: pinned intensity correlation (property), not MCF / Schell theorem (analytical) → partial-coherence broken
- `strehl_vector`: pinned plane-wave=1.0 (property under default-reference design), not high-NA Ez behavior (analytical) → Richards-Wolf claim unverified
- `make_off_axis_parabola`: pinned dict-field correctness (property), not off-axis focal-point location (analytical) → 2 bugs silent

**Pattern recommendation:** For physics-bearing public APIs, EVERY first-class function should have at least ONE analytical-value pin against a closed-form reference.

## Final verdict

**v4.15.0 is a high-velocity high-yield release** that ships major new features (Forbes Q, partial-coherence sources, modal-asymptotic batched cold-start, OAP, 7 new analysis functions, ergonomic system entry, third structural meta-pin). The implementation quality is mostly good — Forbes Q math is correct; the perf win is verified; the v4.14.3 carryover closures are clean.

**However, 2 P0s and 12 P1s materially affect users:**
- `make_off_axis_parabola` produces silently-wrong prescriptions
- Schell-family factories return single coherent fields advertised as partial-coherence sources
- Modal-asymptotic cold-start is unverified despite being marketed as a physics fix
- Forbes Q is half-shipped (math correct, but raytrace + Zemax consumer paths missed)
- UI emits its own deprecation warnings (the release that introduced the deprecation didn't migrate its own UI)
- Sparrow returns 15% below canonical on clean Airy

**Recommendation:** v4.15.1 patch closing the 2 P0s + Tier-0 P1s (~120 LOC + ~10 small tests). Until then, treat:
- `make_off_axis_parabola` as "do not use" (or use only at very small off-axis angles)
- `create_gaussian_schell_source` / `create_schell_model_source` / `create_annular_incoherent_source` as "ensemble-averaged amplitude envelopes, NOT partial-coherence sources"
- `sparrow_resolution` as ~15% biased low on Airy-like PSFs
- Modal-asymptotic v4.15 output as "self-consistent against v4.15 reference, not independently physics-verified"

The fundamental engineering remains strong. The audit-meta-pattern continues at ~5/release; closing it requires extending the meta-pin pattern to analytical-value pins for every physics-bearing API.
