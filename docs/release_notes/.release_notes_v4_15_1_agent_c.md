Patch release closing **4 P1s** + the analytical-value pin
meta-finding from `docs/audits/AUDIT_V4_15_0_2026_05_18.md` against
the v4.15.0 analysis functions in `lumenairy.analysis.core`.

* P1-NEW-A: `sparrow_resolution` returns 15% below canonical Sparrow
  on a clean Airy (returned 1.93 um vs expected 2.27 um at lambda=
  600nm, f/#=4).
* P1-F1-3: `strehl_vector` default-reference branch produces Strehl
  > 1 on focused PSFs (the uniform-plane-wave reference is more
  diffuse than the focused PSF).
* P1-F1-4: `rayleigh_resolution` returns a spurious value on
  Gaussian PSFs (no true first-ring zero).
* P1-F1-5: `astigmatism_mag_angle` docstring claims theta range
  `(-pi/4, pi/4]`; actual range is `(-pi/2, pi/2]`.

Plus three P3 follow-ups:

* `rayleigh_resolution` / `sparrow_resolution` / `fwhm_resolution`
  now thread an optional `dy` kwarg and dispatch via `_xp_of`.
* `strehl_vector` docstring drops the unverified "Richards-Wolf
  high-NA" claim (audit recommendation 9c).
* `astigmatism_mag_angle` docstring updated to the actual
  `(-pi/2, pi/2]` range with a note about canonical-quadrant
  folding.

## Breaking change

**`strehl_vector` now requires an explicit `reference=` keyword
argument.**  The v4.15.0 default-reference branch (uniform plane
wave of matching total power) returned Strehl > 1 for any focused
PSF (silently wrong: a focused PSF concentrates more power into its
peak than a uniform field of the same total power).  Callers must
supply the diffraction-limited reference field for the same
aperture / system explicitly.  See migration recipe below.

Migration recipe:

```python
# v4.15.0 (silently produces Strehl > 1 for focused PSFs):
strehl = la.strehl_vector(Ex_aber, Ey_aber)

# v4.15.1 (raises ValueError if no reference supplied):
psf_ref, _ = la.compute_psf(pupil_unaberrated, wavelength, f, dx)
Ex_ref = np.sqrt(psf_ref).astype(np.complex128)
Ey_ref = np.zeros_like(Ex_ref)
strehl = la.strehl_vector(Ex_aber, Ey_aber,
                          reference=(Ex_ref, Ey_ref))
```

## Files modified

* `lumenairy/analysis/core.py`:
  - `_psf_1d_profile` -- accepts `dy` for anamorphic radial binning.
  - `_radial_profile_subpixel` (new internal helper) -- sub-pixel
    azimuthal averaging via `scipy.ndimage.map_coordinates` for the
    cubic-spline + brentq `sparrow_resolution` path.
  - `_to_numpy_host` (new internal helper) -- CuPy `.get()` /
    JAX `__array__` host transfer for the resolution-metric exit.
  - `rayleigh_resolution` -- adds `dy` kwarg, `_xp_of` dispatch,
    and requires a TRUE local minimum (lookahead-window strict
    rise above the candidate by >= 0.5% of peak) before declaring
    a first-zero.  Returns `NaN` + `RuntimeWarning` on
    Gaussian-like PSFs without a real first ring.
  - `sparrow_resolution` -- rewritten to canonical Sparrow.  Builds
    a sub-pixel azimuthally-averaged radial profile, fits a
    natural-boundary cubic spline, takes the analytic second
    derivative, and uses `scipy.optimize.brentq` to bracket the
    first sign change of I''(r) for r > 0.  Returns `2 * r_zero`.
    Replaces the v4.15.0 `np.gradient`-twice + zero-cross approach
    that was discretisation-biased low.
  - `fwhm_resolution` -- adds `dy` kwarg, `_xp_of` dispatch.
  - `strehl_vector` -- removes default-reference branch, raises
    `ValueError` if `reference` is omitted, drops "Richards-Wolf
    high-NA" claim from docstring (softened to "scalar Strehl-like
    metric over vector field components").
  - `astigmatism_mag_angle` -- docstring range corrected from
    `(-pi/4, pi/4]` to `(-pi/2, pi/2]`, with canonical-quadrant
    folding note.

## Analytical-value pin tolerances chosen

| Pin | Reference value | Tolerance | Rationale |
|---|---|---|---|
| Sparrow on Airy | 0.947 * lambda * f/# | 5% | Canonical Airy Sparrow constant (Sparrow 1916); 5% covers grid discretisation noise on a 256 x 256 PSF at dx_psf = 0.1 um. |
| FWHM on Airy | 1.029 * lambda * f/# | 5% | Standard Airy FWHM-diameter formula (Born & Wolf, §8.5); 5% same rationale. |
| Rayleigh on Airy | 1.22 * lambda * f/# | 5% | Carried over from v4.15.0; first-zero of J1 / x at x = 3.832. |
| theta range (astig) | (-pi/2, pi/2] | strict (1e-12) | atan2 returns (-pi, pi] exactly; the half-angle map is exact. |
| Strehl unaberrated | 1.0 | 1e-12 | Identical field/reference; only rounding. |

## Algorithm-correctness analytical pin (audit meta-finding)

The audit's meta-finding was that v4.15.0 test pins were mostly
PROPERTY pins (orderings, shapes, monotonicity) rather than
ANALYTICAL-VALUE pins.  Property pins miss algorithm-correctness
regressions: the v4.15.0 `sparrow_resolution` passed `< rayleigh`
but returned a 15%-biased low value on a clean Airy.

v4.15.1 follows the audit's "for physics-bearing public APIs, EVERY
first-class function should have at least ONE analytical-value pin
against a closed-form reference" recommendation for the four
resolution / Strehl metrics in scope:

* `sparrow_resolution`: analytical 0.947 * lambda * f/# +/- 5%.
* `fwhm_resolution`: analytical 1.029 * lambda * f/# +/- 5%.
* `rayleigh_resolution`: analytical 1.22 * lambda * f/# +/- 5%
  (carried over).
* `strehl_vector`: round-trip identity-reference pin (Strehl(F, F)
  = 1.0 to roundoff) + monotone-decreasing-under-defocus pin
  (existing).

The two property pins (`sparrow < rayleigh`, `fwhm < rayleigh`) are
kept as sibling pins on top of the analytical-value pins so the
ordering invariant remains explicit.
