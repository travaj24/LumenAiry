## Meta-pin candidate #3 implementation

**File:** `tests/unit/test_v4_15_dispatcher_pin_validate_grid_params.py`

**Discovery walker:** `_discover_create_factories()` -- scans
`lumenairy.sources.core` for every `create_*` factory.  Uses
`__all__` when present + a `dir()` fallback for resilience
against missing or shrunken `__all__`.

**Discovered factories (14):**

- `create_annular_beam`
- `create_annular_incoherent_source`
- `create_bessel_beam`
- `create_fiber_mode`
- `create_gaussian_beam`
- `create_gaussian_schell_source`
- `create_hermite_gauss`
- `create_laguerre_gauss`
- `create_led_source` (XFAIL -- documented exemption due to
  legacy-positional shim)
- `create_multi_field_sources`
- `create_point_source`
- `create_schell_model_source`
- `create_tilted_plane_wave`
- `create_top_hat_beam`

**Pre-flight guards:**

1. `test_walker_found_at_least_eight_factories` -- count floor
   at 8.  Catches walker breakage / accidental factory removal.
2. `test_counter_pin_fake_unvalidated_factory_fails` -- inject
   synthetic unvalidated factory; assert the meta-pin would
   catch it.  Counter-pin against false-negatives.
3. `test_counter_pin_fake_validated_factory_passes` -- inject
   synthetic validated factory; assert the meta-pin would pass
   it.  Counter-pin against false-positives.

**Documented exemption set (`_KNOWN_VALIDATION_EXEMPTIONS`):**

- `create_led_source` -- legacy positional shim runs FIRST so
  the validate call lands at line ~145 of the function body,
  past the 15-line head window.  Re-ordering to put validate
  before the shim would break legacy callers (shim re-maps
  positions 2-4, so wavelength validation would compare against
  legacy `diameter` value).  When the legacy shim is removed at
  v5.0 this xfail flips to XPASS and the exemption is removed.

- 14 parametrized factory checks (13 PASSED + 1 XFAIL)
- 3 pre-flight guards (PASSED)
- 1 diagnostic helper (PASSED)
