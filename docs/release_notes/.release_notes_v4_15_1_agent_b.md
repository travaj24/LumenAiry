## P0-NEW-2 -- Schell-family factories redesigned for actual partial coherence

The v4.15.0 release of `create_gaussian_schell_source`,
`create_schell_model_source`, and `create_annular_incoherent_source`
shipped a contract bug (3-way confirmed in
`docs/audits/AUDIT_V4_15_0_2026_05_18.md`, P0-NEW-2): all three
factories computed an ensemble of random-phase realisations and then
COLLAPSED it to a single complex field

```
E = sqrt(<I>) * exp(i * angle(<E>))
```

before return.  The returned single field has fully-coherent MCF
`J(r1, r2) = E*(r1) * E(r2)`, NOT the documented Schell-model
factorisation `sqrt(I(r1) I(r2)) * mu(r1 - r2)`.  Downstream callers
using the result as a "partial-coherence source" received a fully
coherent answer.

The audit also flagged a unit-RMS phase normalisation at
`sources/core.py:1476-1481` (Gaussian-Schell) and `:1588-1592`
(generic Schell) that forced `sigma_phi == 1` regardless of `sigma_g`,
so neither the `sigma_g -> 0` (incoherent) nor the
`sigma_g -> infinity` (coherent) limit was recovered.

### Resolution: hybrid ensemble / MCF return contract

The user decision was a hybrid contract:

- **Default `return_kind='ensemble'`**: each factory returns
  `(E_ensemble, dx, dy, wavelength)` where `E_ensemble` has shape
  `(n_realizations, Ny, Nx)`.  Caller iterates over realisations and
  averages intensities downstream -- physically correct partial
  coherence.
- **Opt-in `return_kind='mcf'`**: each factory returns a
  `PartialCoherenceMCF` instance.

The v4.15.0 single-field return signature is gone.  No back-compat
shim -- the user is the sole consumer of the library, and a
deprecation-shim that returned a misleading "average envelope" would
just propagate the original P0 bug under a deprecation warning.

### `PartialCoherenceMCF` dataclass (NEW)

```python
@dataclass
class PartialCoherenceMCF:
    shape: Tuple[int, int]
    dx: float
    dy: float
    wavelength: float
    J_full: Optional[np.ndarray] = None             # (Ny*Nx, Ny*Nx)
    modes: Optional[np.ndarray] = None              # (K, Ny, Nx)
    eigenvalues: Optional[np.ndarray] = None        # (K,)
    n_realizations: Optional[int] = None
```

Two storage forms, selected automatically by `from_ensemble`:

- **Full** -- the dense `(Ny*Nx, Ny*Nx)` MCF matrix `J_full`.
  Used when `Ny*Nx <= max_full_N**2` (default `max_full_N=64`, i.e.
  up to `64 x 64` grids -- the dense MCF is then `4096 x 4096 ~=
  256 MiB complex128`, which is the practical ceiling for in-memory
  full storage on a workstation).
- **Modal** -- a coherent-mode decomposition (Mandel & Wolf,
  _Optical Coherence and Quantum Optics_, Section 4.7;
  Wolf 1982 JOSA 72 343).  Stores the leading `K` eigenmodes
  `modes[k, :, :]` and eigenvalues `eigenvalues[k]` such that
  `J(r1, r2) ~= sum_k lambda_k * mode_k(r1) * conj(mode_k(r2))`.

The decomposition is computed via SVD of the ensemble matrix
`E_mat` of shape `(n_realizations, Ny*Nx)`: the eigenmodes of
`J = (1/K) * E_mat^H @ E_mat` are the right-singular vectors of
`E_mat`, and the eigenvalues are `s_i^2 / n_realizations`.  This
avoids ever materialising the dense MCF for large N.

API:

- `mcf.intensity()` -- the `(Ny, Nx)` intensity diagonal of `J`.
- `mcf.coherence_at(ix1, iy1, ix2, iy2)` -- the complex coherence
  factor `J(r1, r2) / sqrt(I(r1) I(r2))`.  `|mu|` is bounded by 1
  (Schwarz); `|mu| == 1` is fully coherent, `|mu| == 0` fully
  incoherent.
- `mcf.coherent_modes()` -- `(modes, eigenvalues)` of the coherent-
  mode decomposition.  In modal storage, returns the stored arrays;
  in dense storage, computes the Hermitian eigendecomposition of
  `J_full` on demand.

Note: MCF-aware downstream propagators (Koehler-/Hopkins-style
coherent-mode propagation, MCF transport through the system) are NOT
in v4.15.1 scope and are deferred to v4.16+.  The current
`PartialCoherenceMCF` is consumable for inspection / analysis only
(intensity, two-point coherence, coherent-mode extraction).

### Explicit Schell kernel + spatially-filtered-noise formulation

For a Gaussian-Schell beam the spatial coherence kernel is

```
mu(Delta_r) = exp(-|Delta_r|^2 / (2 * sigma_g^2))
```

To generate `n_realizations` random fields `phi_k(r)` with this
two-point correlation we use the recipe (Goodman, _Statistical
Optics_, Sec 5.5):

1. For each realisation, draw circular-Gaussian complex white noise
   `W_k(r)` on the grid: independent `N(0, 1/2)` real and imaginary
   parts, so `<|W(r)|^2> = 1` and `<W(r) conj(W(r'))> = delta(r-r')`.
2. Multiply by the Fourier-space Gaussian filter
   `H(k) = exp(-|k|^2 * sigma_g^2 / 4)` and inverse-FFT to obtain
   the band-limited complex random field `phi_k(r)`.  The factor of
   4 in the exponent (rather than 2) is because the convolution-
   square of a Gaussian of width `sigma` is a Gaussian of width
   `sigma * sqrt(2)`, so a real-space coherence width of `sigma_g`
   requires a real-space convolution kernel of width
   `sigma_g / sqrt(2)`, i.e. Fourier filter
   `exp(-|k|^2 * sigma_g^2 / 4)`.
3. Normalise so the mean intensity per realisation is unity:
   `phi <- phi / sqrt(<|phi(r)|^2>_r)`.  `|phi|^2` then averages to
   1; the resulting field acts as the random "phase + speckle"
   factor of the Schell-model decomposition.
4. The k-th ensemble realisation is `E_k(r) = sqrt(I(r)) * phi_k(r)`,
   so the ensemble MCF
   `J(r1, r2) = <E(r1) * conj(E(r2))>
              = sqrt(I(r1) I(r2)) * exp(-|r1-r2|^2 / (2 sigma_g^2))`
   which is the Schell-model factorisation with Gaussian kernel.

This produces phase realisations with the right two-point correlation
WITHOUT the v4.15.0 unit-RMS bug.  The two limits are recovered:

- `sigma_g -> 0`: the Fourier-space filter `exp(-|k|^2 sigma_g^2/4)`
  approaches 1 (flat), so `phi` approaches white noise per pixel and
  `mu(Delta_r != 0)` decays to zero.  Test
  `test_gaussian_schell_incoherent_limit` (`sigma_g = dx / 10`,
  `n_realizations = 2000`) pins the mean off-diagonal `|mu|` to
  `< 0.10` (statistical bound `1 / sqrt(n_real) ~= 0.022`).
- `sigma_g -> infinity`: the Fourier-space filter becomes very
  narrow, so `phi(r)` is essentially constant in space, all
  realisations differ only by a global phase, and `J` is rank-1
  (one fully-coherent mode).  Test
  `test_gaussian_schell_coherent_limit` (`sigma_g = 100 * (N * dx)`)
  pins the leading eigenvalue ratio to `> 0.99`.

The kernel value at intermediate separations matches theory.  Test
`test_gaussian_schell_coherence_kernel_matches_theory` (N=32,
`sigma_g = 20e-6 = 10*dx`, `n_realizations = 64`) compares the
measured `|mu(k*dx)|` at `k = 1, 3, 5, 8` against the predicted
`exp(-(k*dx)^2 / (2*sigma_g^2))` and asserts agreement within 15%
(finite-sample tolerance for a 64-draw MCF estimate).

### Annular-incoherent source

`create_annular_incoherent_source` retains its original
"per-pixel independent uniform-(-pi, pi) phase" semantics (i.e.
fully spatially-incoherent at the source plane, the classic
"non-zero source size for partial-coherence integration" recipe),
but no longer collapses the ensemble: it returns either the raw
`(n_realizations, Ny, Nx)` realisations or a `PartialCoherenceMCF`
with a nearly-diagonal MCF.

### `n_modes` truncation decision

When `Ny*Nx > max_full_N**2` we cannot afford the dense `J_full`, so
`PartialCoherenceMCF.from_ensemble` falls back to a coherent-mode
decomposition.  The truncation rank `K` is chosen by:

- **Explicit `n_modes`** kwarg if supplied (any value in
  `[1, min(n_realizations, N_pix)]`).
- **Otherwise**: the smallest `K` such that the cumulative
  eigenvalue mass `sum_{i=0..K-1} lambda_i / sum_total >=
  energy_threshold` (default `0.99`).  This is the standard
  Karhunen-Loeve truncation criterion -- for a fully coherent source
  it returns `K = 1`; for an incoherent source on a small grid it
  returns up to `K = min(n_realizations, N_pix)`.

The 99%-energy threshold is a defensible default because:
- It preserves the bulk of the source's mutual-coherence structure
  in the "few coherent modes" regime (Wolf 1982 demonstrated that
  partially-coherent sources are typically dominated by 1-10
  coherent modes).
- It is consistent with the literature convention for coherent-mode
  truncation (e.g. Saastamoinen 2013, _Coherent-mode decomposition
  for partially coherent imaging_).
- It scales naturally with `n_realizations`: when the user supplies
  more realisations the truncation captures more of the spectrum,
  but never more than the rank of the ensemble matrix.

### Migration guide

Pre-v4.15.1 callers wrote:

```python
E, x, y = la.create_gaussian_schell_source(
    N=64, dx=2e-6, wavelength=633e-9,
    w0=20e-6, sigma_g=5e-6, n_realizations=8)
# E was a (64, 64) complex array; x, y were 1-D coordinate axes.
```

v4.15.1 callers write either:

```python
# Default ensemble contract:
ens, dx, dy, wl = la.create_gaussian_schell_source(
    N=64, dx=2e-6, wavelength=633e-9,
    w0=20e-6, sigma_g=5e-6, n_realizations=8)
# ens has shape (8, 64, 64); average intensities downstream.
I = np.mean(np.abs(ens) ** 2, axis=0)
```

```python
# Opt-in MCF contract:
mcf = la.create_gaussian_schell_source(
    N=64, dx=2e-6, wavelength=633e-9,
    w0=20e-6, sigma_g=5e-6, n_realizations=8,
    return_kind='mcf')
# mcf is a PartialCoherenceMCF; query .intensity(), .coherent_modes(),
# .coherence_at(...).
```

The matching `Source.gaussian_schell` and `Source.schell_model`
classmethods follow the same convention.  In `return_kind='ensemble'`
mode they wrap the ensemble in a `Source` (the `Source.E` carries
the full `(n_realizations, Ny, Nx)` array, and `Source.shape`
returns the trailing `(Ny, Nx)` -- consistent with the existing
`Source.shape` convention `tuple(self.E.shape[-2:])`).  In
`return_kind='mcf'` mode they return the bare `PartialCoherenceMCF`
object (not wrapped in a `Source`, since the propagator pipeline
currently consumes only a single complex field).
