## C.1 -- P2-NEW-F1-A: SAS-anamorphic CHANGELOG wording

### What the audit caught

The v4.15.3 entry's P1-NEW-F1-1 bullet asserted v4.15.3 fixes the
SAS-anamorphic crash by "forc[ing] `method='asm'` regardless of
`self.method` when `dy != dx`".  The actual code at
`lumenairy/algebra/primitives.py:148-150` reads:

```python
method = self.method
if anamorphic and method == 'auto':
    method = 'asm'
```

The `if anamorphic and method == 'auto':` gating means explicit
`method='sas'` on an anamorphic input still routes to SAS and
crashes with `TypeError: scalable_angular_spectrum_propagate() got
an unexpected keyword argument 'dy'`.  The in-code comment at
`algebra/primitives.py:142-147` correctly documents this as
intentional (explicit `method=` choice is the user's
responsibility); only the CHANGELOG misstated the scope.

### What v4.15.4 ships

In-place CHANGELOG correction matching the audit's recommended
wording verbatim:

> *"v4.15.3 forces `method='asm'` when `self.method == 'auto'` and
> `dy != dx`.  Explicit `method='sas'` on anamorphic grids still
> crashes (user's responsibility -- the in-code comment at
> `algebra/primitives.py:142-147` documents this gating)."*

Pinned by `test_changelog_sas_anamorphic_wording_includes_auto_qualifier`,
which asserts both the new qualifier appears AND the pre-correction
"regardless of `self.method`" phrasing is gone.

## C.6 -- Optional Tier-1 meta-pin (audit recommendation)

The audit's Section 5 Tier-1 (Address before v4.16) item #1
recommends:

> "Add a CHANGELOG arithmetic meta-pin: assert that the per-agent
> test-count breakdown sums to the stated net delta, and that the
> final test count matches the actual `pytest --collect-only`
> count."

This agent implemented a best-effort variant as
`test_changelog_per_agent_breakdown_sums_to_net_delta`:

* Parses the v4.15.3 entry's per-agent breakdown line using a
  defensive `A=N, B=N, ...` regex that survives most minor
  wording variations.
* Locates the stated total via `Per-agent sum: **N**` (the
  v4.15.4 wording) OR `Net +N` (the legacy wording) -- whichever
  appears first.
* Asserts equality.
* Uses `pytest.xfail()` (not `pytest.fail`) on parser failures
  rather than breaking CI -- if a future CHANGELOG entry uses
  wording the parser doesn't recognise, the meta-pin xfails
  with a clear "wording drift, defer to v4.16+ generalisation"
  message rather than collapsing the build.

**Status:** implemented (not deferred).  The pin currently passes
at v4.15.3 wording (88 == 88).  A future v4.16+ generalisation
could extend it to walk every CHANGELOG entry from v4.13.0
forward; this agent left that for the v4.16 ROADMAP item "doc-
reconciliation meta-pin" (Tier-1 item #2) which is broader scope.
