## v4.15.4 -- Agent D scope: OPD fan + summary plotting helpers

Adds two new public plotting functions that fill the gap between the
existing 2-D wavefront map (`plot_wavefront`, v4.14.0) and the 1-D fan
compute helper (`raytrace.opd_fan_data`).  Both functions match the
visual style of the cross-check figures at
`OPDPy_Lumenairy_Crosscheck/fig_variety_L*.png` and are composable --
`plot_opd_summary` delegates to `plot_wavefront` for the heatmap panel
and to the same internal renderer used by `plot_opd_fan` for the fan
panels, so there is no code duplication.

### D.1 -- `plot_opd_fan(py, opd_y, px, opd_x, *, ...)`

Two-panel OPD-vs-pupil ray-fan plot.

* Left panel: tangential fan -- `opd_y` vs `py`, titled
  "y-fan (tangential)".
* Right panel: sagittal fan -- `opd_x` vs `px`, titled
  "x-fan (sagittal)".
* `figsize=(12, 4.5)` default; tunable via existing `fig` / `axes`
  kwargs.
* `units` selector mirrors `plot_wavefront`: `'waves'` (requires
  `wavelength`), `'nm'`, `'um'`, `'m'`.  Inputs are assumed in
  metres so `units='waves'` divides by `wavelength`.
* `show_stats=True` overlays "PV: ..., RMS: ..." in the upper-left of
  each panel, computed over the finite (in-aperture) portion of each
  fan -- NaN entries from vignetted / TIR'd rays are tolerated.
* Horizontal `axhline(0, color='gray', lw=0.5, alpha=0.5)` reference
  line on each panel.
* Returns `(fig, (ax_y, ax_x))` -- ax_y is tangential, ax_x is sagittal.

Documents a unit gotcha for users feeding directly from
`raytrace.opd_fan_data`: that function returns OPD in **waves**, but
`plot_opd_fan` expects metres so the `units='waves'` branch can divide
by `wavelength`.  Callers must either multiply the fan output by the
trace wavelength before passing, or pass `units='m'` and the data
will render with the "OPD (m)" label.

**LOC**: 147 (lines 1214-1360 of `lumenairy/analysis/plotting.py`).

### D.2 -- `plot_opd_summary(opd_2d, dx, *, ...)`

Four-panel OPD summary in a 2x2 grid:

* (0, 0) 2-D OPD heatmap -- delegates to `plot_wavefront`.
* (0, 1) Radial RMS profile -- RMS of the in-aperture OPD evaluated in
  32 radial bins from the centre.  X-axis = normalised radius in
  `[0, 1]`; Y-axis = RMS in the chosen units.
* (1, 0) Tangential fan -- explicit `(py, opd_y)` if supplied, else
  central column of `opd_2d`.
* (1, 1) Sagittal fan -- explicit `(px, opd_x)` if supplied, else
  central row of `opd_2d`.

`figsize=(12, 10)` default.  Returns
`(fig, ((ax_hm, ax_rms), (ax_y, ax_x)))`.

**Design choice -- extract-from-2D fallback**: the fan kwargs
`(py, opd_y, px, opd_x)` are optional.  When **all four** are supplied
(typical when the caller has run `raytrace.opd_fan_data` already, which
gives chief-ray-referenced OPDs at high pupil sampling), they are
rendered directly.  When **any** are `None` the function extracts the
central row + column of `opd_2d` so the figure still populates for
callers that only have the 2-D map.  This means the function is
useful both as a one-call diagnostic from a single `opd_2d` array
**and** as a publication-quality figure when the caller has both
wave-side and ray-side data.

**LOC**: 204 (lines 1420-1623 of `lumenairy/analysis/plotting.py`).
Internal helpers add another ~100 lines:

* `_resolve_opd_units` (29 LOC): centralises the `units`/`wavelength`
  -> (scale, label) conversion used by both functions.
* `_opd_pv_rms_1d` (15 LOC): PV/RMS over the finite portion of a 1-D
  OPD fan.
* `_render_opd_fan_panel` (35 LOC): renders one fan panel onto an
  existing axis -- used by both `plot_opd_fan` and `plot_opd_summary`.
* `_radial_rms_profile` (55 LOC): bins the 2-D OPD into radial annuli
  and returns the per-bin RMS.

### Example -- `examples/plot_opd_summary_singlet.py`

Builds an N-BK7 singlet (R1=+50 mm, R2=-50 mm, d=4 mm, A=10 mm,
1 m object distance), computes:

* 2-D OPD via `eval_image_plane_wfe` (chief-ray reference sphere,
  paraxial focus).
* 1-D fans via `opd_fan_data` (chief-ray reference, 101 samples
  per fan).

Then calls `plot_opd_summary` with both the 2-D OPD and the explicit
fan arrays and saves the figure as `singlet_opd_summary.png`.

**Example PV/RMS output** (at 633 nm):

```
Singlet N-BK7 R1=+50/R2=-50 mm, d=4 mm, A=10 mm, lambda = 633 nm
  2-D OPD: PV = 2.9318 waves, RMS = 1.3347 waves
```

The singlet at this aperture / focal-length combination is heavily
spherically aberrated (a textbook outcome), which makes it a good
demonstration target -- the radial-RMS panel clearly shows the
spherical-build-up signature, and the two fan panels show the
characteristic cubic shape of marginal-ray spherical at the edges.
