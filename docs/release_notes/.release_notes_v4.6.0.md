**Documentation overhaul — decision-tree front door + lens-family cross-refs.**  No code changes; the public API and wheel contents are bit-identical to 4.5.0.  `pip install --upgrade lumenairy` only delivers the documentation.

The 4.5 ship was a code-complete world-frame story, but the README — the front door for new users — was still the same dense feature-list it had been since 3.x.  4.6 fixes that without touching a single line of library code.

## Changed (documentation only)

* **README "Quick start: which function should I use?"** — five decision-tree tables replacing the former monolithic Quick Start.  One table for each user question: free-space propagation, lens application, folded designs, output-field analysis, optimisation / tolerancing.  Three minimal end-to-end examples follow.

  The longer recipes (Zernike decomposition, phase retrieval, HDF5 storage, polarization, plotting, etc.) moved into a new `## Cookbook` section near the bottom of the README — nothing was removed, just relocated so they don't crowd the first-read experience.

* **`apply_real_lens` / `_traced` / `_maslov` docstrings now cross-link.**  Each opens with a `See Also` block + a one-line `Quick decision guide`, so `help(la.apply_real_lens)` makes the three-way fidelity choice obvious right at the top:

  * Default fast wave model → `apply_real_lens`
  * Sub-nm OPD on cemented doublets → `apply_real_lens_traced`
  * Inside a JAX autodiff loop or near a caustic → `apply_real_lens_maslov` / `apply_real_lens_maslov_jax`

* **Dense physics citations moved out of the README's main flow.**  Matsushima-Shimobaba, Heintzmann-Loetgering-Wechsler, Maslov integral details, and the per-variant real-lens accuracy strategy now live in `Appendix: Physics references` at the bottom — still here for anyone who wants them, just out of the way on first read.  The dense per-variant paragraphs in `Key Features → Lenses` were trimmed to one-line summaries that point at the docstrings + appendix.

## No code changes

The public API, all imports, exports, and wheel contents are bit-identical to 4.5.0.  Existing scripts are unaffected; no validation changes required.
