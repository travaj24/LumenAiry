### D.1 -- Forbes Q-bfs and Q-con orthonormal freeform polynomial bases

Two new top-level functions land in `lumenairy/elements/freeform.py`:

* `surface_sag_q_bfs(X, Y, *, radius, coefficients, r_max, dx, dy=None, norm_x=1.0, norm_y=1.0)` -- Forbes 2007 Eq. 13 best-fit-sphere-subtracted basis:

  ```
  z(r) = z_bfs(r) + u^2 * (1 - u^2) * sum_{m=0}^{M} a_m * Q_m^bfs(u^2)
  ```

* `surface_sag_q_con(X, Y, *, radius, conic, coefficients, r_max, dx, dy=None, norm_x=1.0, norm_y=1.0)` -- Forbes 2010 Eq. 6 conic-subtracted basis:

  ```
  z(r) = z_conic(r) + u^4 * sum_{m=0}^{M} a_m * Q_m^con(u^2)
  ```

`u = r / r_max` is the normalised radial coordinate.

**Orthonormality conventions** (pinned with high-resolution trapezoidal quadrature in the new tests):

* Q-bfs:  `int_0^1 Q_m(u^2) Q_n(u^2) u^2 (1 - u^2) d(u^2) = delta_{mn}`.
* Q-con:  `int_0^1 Q_m(u^2) Q_n(u^2) u^4 d(u^2) = delta_{mn}`.

**Recurrence formulas used**.  Forbes 2010 Sec. 3 derives explicit 3-term recurrences for both bases as specialisations of the shifted Jacobi recurrence.  The implementation uses the standard Jacobi 3-term form (A&S 22.7.1):

```
2(n+1)(n+alpha+beta+1)(2n+alpha+beta) P_{n+1}(t)
  = (2n+alpha+beta+1) * [(2n+alpha+beta)(2n+alpha+beta+2) t + alpha^2 - beta^2] P_n(t)
    - 2 (n+alpha) (n+beta) (2n+alpha+beta+2) P_{n-1}(t)
```

with `P_0(t) = 1`, `P_1(t) = (1/2) [(alpha - beta) + (alpha + beta + 2) t]`, evaluated at `t = 2u^2 - 1` on `[-1, 1]`, then multiplied by the orthonormalisation factor

```
c_n = 1 / sqrt(int_0^1 [P_n^(alpha,beta)(2x - 1)]^2 (1-x)^alpha x^beta dx)
    = 2^(-(alpha+beta+1)/2) / sqrt(h_n)
```

where `h_n` is the standard `[-1, 1]` Jacobi norm `h_n = 2^(alpha+beta+1) Gamma(n+alpha+1) Gamma(n+beta+1) / ((2n+alpha+beta+1) n! Gamma(n+alpha+beta+1))`.  Specialisations:

* Q-bfs: `(alpha, beta) = (1, 1)`, giving `c_n = sqrt((2n+3)(n+2) / (n+1)^2)` so e.g. `Q_0^bfs(x) = sqrt(6)` constant, `Q_1^bfs(x) = sqrt(15) (2x - 1)`, ...
* Q-con: `(alpha, beta) = (0, 2)`, giving `c_n = sqrt(2n+3)` so e.g. `Q_0^con(x) = sqrt(3)` constant, `Q_1^con(x) = sqrt(5) (4x - 3)`, ...

Internal helpers `_q_bfs_eval(x, n)`, `_q_con_eval(x, n)`, `_shifted_jacobi_eval(x, n, alpha, beta)`, and `_jacobi_norm_factor(n, alpha, beta)` live in the same module.

**Negative-norm guards** apply the v4.14.3 P1-NEW-11 convention (`norm_x` / `norm_y` must be positive finite half-extents); analogous guards on `r_max`, `dx`, `dy` reject zero / negative / non-finite values.  Outside the rectangular `[-norm_x, norm_x] x [-norm_y, norm_y]` box the freeform departure is zeroed so the ray tracer does not see a discontinuity at the rim.

**Array-namespace dispatch**.  Both sag functions use the `_xp_of` helper (mirroring `elements.elements` and `analysis.core`) so they remain NumPy / CuPy / JAX polymorphic.

**Dispatcher extension**.  `surface_sag_freeform` recognises two new `freeform_type` strings, `'q_bfs'` and `'q_con'`, reading `q_bfs_coeffs` / `q_con_coeffs` and `r_max` from the surface dict.  A best-effort `dx` fallback derives the grid stride from the X column spacing if `dx` is not present in the dict.

### D.2 -- `make_off_axis_parabola` prescription factory

Adds `make_off_axis_parabola(focal_length, off_axis_angle, clear_aperture, *, glass='__MIRROR__', vertex_radius=None, name=None) -> dict` in `lumenairy/io/prescriptions.py`.

Returns a single-surface prescription dict with:

* `radius = 2 * focal_length` (geometric relation for the parent paraboloid, or override via `vertex_radius`).
* `conic = -1.0` (paraboloid).
* `decenter = (focal_length * tan(off_axis_angle), 0.0)` -- parent-axis offset to the OAP centre.
* `tilt = (off_axis_angle, 0.0, 0.0)` -- 3-tuple local-frame tilt per task spec.
* `aperture_diameter = clear_aperture` at the top level plus `clear_aperture` on the surface.
* `glass_before = 'air'`, `glass_after = 'air'` when `is_mirror=True`, else `glass_after = glass`.
* `is_mirror = (glass == '__MIRROR__')`.

Input validation rejects `focal_length <= 0`, `off_axis_angle <= 0` or `>= pi/2`, and `clear_aperture <= 0` with descriptive `ValueError`s.

### Notes on the Forbes recurrence coefficient formulas

The task brief asked for the explicit coefficients used.  The 3-term Jacobi recurrence is parametrised by `(alpha, beta)`:

```
a1 P_{n+1} = (a2 t + a3) P_n - a4 P_{n-1}
```

with

```
a1 = 2 (n+1) (n + alpha + beta + 1) (2n + alpha + beta)
a2 = (2n + alpha + beta + 1) (2n + alpha + beta) (2n + alpha + beta + 2)
a3 = (2n + alpha + beta + 1) (alpha^2 - beta^2)
a4 = 2 (n + alpha) (n + beta) (2n + alpha + beta + 2)
```

For **Q-bfs**:  `(alpha, beta) = (1, 1)` (weight `x (1-x) dx` on `[0, 1]`).  Simplifying:

```
a1 = 2 (n+1) (n+3) (2n+2)
a2 = (2n+3) (2n+2) (2n+4)
a3 = 0  (alpha^2 = beta^2)
a4 = 2 (n+1)^2 (2n+4)
```

For **Q-con**:  `(alpha, beta) = (0, 2)` (weight `x^2 dx`).  Simplifying:

```
a1 = 2 (n+1) (n+3) (2n+2)
a2 = (2n+3) (2n+2) (2n+4)
a3 = -4 (2n+3)
a4 = 2 (n+1) (n+2) (2n+4)
```

Orthonormalisation factors:

* Q-bfs:  `c_n = sqrt((2n+3) (n+2) / (n+1)^2)`.
* Q-con:  `c_n = sqrt(2n+3)`.

These match Forbes 2010 Sec. 3 (the paper presents the recurrence in a slightly compacted form via the substitution `x = u^2`; the present implementation works in the shifted Jacobi variable `t = 2x - 1` for numerical-stability reasons).  Both bases were verified against the high-resolution numerical orthonormality matrices in `test_q_bfs_orthonormality_first_5_orders` and `test_q_con_orthonormality_first_5_orders`, with all off-diagonal terms below 1e-6 and diagonal terms within 1e-6 of 1.0.
