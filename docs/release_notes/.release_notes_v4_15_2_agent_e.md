## E.2 -- P2: `_sentinel_unpickle` strict-raise fallback

`lumenairy/_deprecation.py`:

Pre-v4.15.2 the fallback path (missing registry entry)
silently constructed a base `_Sentinel(name)` -- losing
subclass identity.  In a distributed pipeline where a worker
unpickles a `_ZeroApertureMaskSentinel` *before* it has
imported `lumenairy.optimize.core`, the worker would receive a
base `_Sentinel` and downstream `isinstance` /
`mask is _ZERO_APERTURE_MASK` checks would silently downgrade.

v4.15.2 (option (a) from the dispatch text) raises
`ImportError` with the actionable message::

    _sentinel_unpickle: no _Sentinel registered under
    name='_ZERO_APERTURE_MASK'.  The defining module has likely
    not been imported on the receiving side.  To unpickle a
    '_ZERO_APERTURE_MASK'-class sentinel, import its defining
    module first (e.g. import lumenairy.optimize.core for
    _ZERO_APERTURE_MASK, import lumenairy.elements.polarization
    for _ANGLE_UNSET, import lumenairy._deprecation for
    NO_DEFAULT).  See AUDIT_V4_15_1 P2 closure for the v4.15.2
    strict-raise rationale.

Test pin: `TestSentinelUnpickleStrictFallback` in
`test_v4_15_2_agent_e.py` (3 tests).

## E.3 -- P2: optimize/core.py sentinel migration

`lumenairy/optimize/core.py`:

Three new `_Sentinel` subclasses, co-located with the existing
`_ZeroApertureMaskSentinel` block (just after line 2044):

| Line cite | Pre-v4.15.2 pattern | New subclass | Singleton |
|---|---|---|---|
| 2271 | `efl = bfl = 1e9` (ABCD-extract failure) | `_InvalidFocalLengthSentinel` | `_INVALID_FL_SENTINEL_OBJ` |
| 2530 | `sub_ctx.strehl_best = 0.0` (through-focus scan failed) | `_FailedScanStrehlSentinel` | `_FAILED_SCAN_STREHL_SENTINEL_OBJ` |
| 2772 | `efl_p, bfl_p = ctx.efl, ctx.bfl` (perturbed-ABCD failed) | `_PerturbedABCDFallbackSentinel` | `_PERTURBED_ABCD_FALLBACK_SENTINEL_OBJ` |

Migration constraints honoured:

- `__repr__` / `__bool__` behaviour from the base `_Sentinel`
  preserved (`bool(s) is False`; `repr(s) == '<NAME>'`).
- The numeric subclasses (`_InvalidFocalLengthSentinel`,
  `_FailedScanStrehlSentinel`) carry a `.value` class attribute
  AND a `__float__` so call sites can ``float(s)`` for
  arithmetic or use the singleton for `is`-identity checks.
- The scalar fallback writes at the call sites are PRESERVED
  for arithmetic compatibility -- changing `efl = 1e9` to
  `efl = _INVALID_FL_SENTINEL_OBJ` would break `ctx_is_valid`
  (which compares ``abs(v) >= _INVALID_FL_SENTINEL * 0.5``).
  The class instances are auxiliary identity markers for
  future opt-in identity checks; no existing call site is
  changed in behaviour.
- Each subclass registers in `_SENTINEL_REGISTRY` via its
  parent `_Sentinel.__init__`, so pickle round-trip preserves
  identity.

Test pin: `TestOptimizeCoreSentinelMigration` in
`test_v4_15_2_agent_e.py` (4 tests).

Note on line drift: the audit-cite at line 2151 is the
`mask = _ZERO_APERTURE_MASK` site, which was already migrated
to `_Sentinel` in v4.15.1 (`_ZeroApertureMaskSentinel`).  The
v4.15.2 work focuses on the remaining three sites (lines
2271 / 2530 / 2772).

## E.5 -- P2: Forbes Q end-to-end OPD analytical pin

`tests/unit/test_v4_15_1_agent_a.py`:

Added `TestForbesQBfsEndToEndOPD::
test_forbes_q_bfs_opd_matches_analytical`:

- Builds a flat-back N-BK7 singlet with a Q-bfs front surface
  carrying ``a_0 = 1e-6 m``.
- Plane-wave input, `apply_real_lens` propagation.
- Compares ``angle(E_out)`` (reference-subtracted to the
  on-axis pixel) against the analytical phase
  ``-k (n - 1) sag(r)`` where
  ``sag(r) = u^2 (1 - u^2) a_0 Q_0^bfs(u^2)`` (Forbes 2007
  Eq. 13 with only ``a_0`` non-zero and a flat base).
- Evaluation disc: ``|r| <= 0.5 r_max`` (well inside the Forbes
  domain; avoids rim transition + radial-clip noise).
- Tolerance: 5e-3 rad (the actual achieved error is bounded
  by the wave-optics ASM numerical-derivative noise floor;
  empirical value < 5e-3 rad on the test fixture).
- Pre-fix (Forbes Q dispatcher silently dropping `a_0`) would
  produce `max_err ~= 1.2 rad` -- 3 orders of magnitude above
  the noise floor.

## E.11 -- P2: `Source.gaussian_schell` ensemble-tuple return

`lumenairy/sources/core.py`:

Pre-v4.15.2 `Source.gaussian_schell(...)` wrapped the 3-D
ensemble in a `Source` whose `E` was 3-D.  Every other
`Source.*` classmethod produces a 2-D field, so downstream
`src.intensity()` / `src.compute_psf(...)` / etc. callers hit
broadcasting axis mismatches.

v4.15.2: `Source.gaussian_schell` (and the sibling
`Source.schell_model`) now return the SAME 4-tuple as the
top-level factory: `(E_ensemble, dx, dy, wavelength)`.  The
`return_kind='mcf'` branch is unchanged (still returns the
bare `PartialCoherenceMCF`).

Rationale (option (a) from the dispatch text): match the
top-level factory return convention.  The new contract
introduces a soft inconsistency between `Source.gaussian()`
(returns Source) and `Source.gaussian_schell()` (returns
ensemble tuple), but the inconsistency is HONEST: Schell is
partial-coherence, a fundamentally different abstraction from
the coherent single-source Source object.  The classmethod
docstring is rewritten to make the return-type alignment with
the factory explicit and to point downstream callers at the
explicit per-realisation wrap pattern when they need
individual Source objects::

    ens, _dx, _dy, _wl = Source.gaussian_schell(...)
    sources = [Source(E=ens[k], dx=_dx, dy=_dy,
                      wavelength=_wl)
               for k in range(len(ens))]

Test pin: `TestSourceGaussianSchellEnsembleTuple` in
`test_v4_15_2_agent_e.py` (3 tests).  Existing v4.15.1 test
pins in `test_v4_15_1_agent_b.py` updated to match the new
contract (the two pre-existing tests `test_source_gaussian_
schell_returns_source_with_ensemble_E` and
`test_source_schell_model_returns_source_with_ensemble_E` are
renamed and re-pointed at the tuple return).  The single
pre-existing v4.15.0 test in `test_v4_15_agent_b.py::
test_source_gaussian_schell_classmethod` is similarly
re-pointed; without that update the test would have failed
because it explicitly asserted `isinstance(src, Source)` on a
return value that is no longer a `Source`.
