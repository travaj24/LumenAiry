# v4.15.1 Agent F -- release notes draft

**Agent role:** F (v4.15.1 / Cluster B Item 6 -- `rays_from_field`
bridge function).  Additive feature, no API changes elsewhere.

## Scope

Implements the wave-to-ray bridge function specified in
`docs/audits/CLUSTER_B_SPEC.md` §4 ("Rays from Coherent Field").  The
function samples a coherent complex field `E(x, y)` into a geometric
`RayBundle`:

* Position is drawn from the field's intensity distribution via one of
  three placement strategies (`cdf`, `rejection`, `uniform`).
* Direction comes from the local k-vector at each ray's origin pixel:
  `(L, M) = (k_x, k_y) / k0`, `N = sqrt(1 - L^2 - M^2)`, with
  `RAY_EVANESCENT` flagging for any ray whose `L^2 + M^2 > 1`.
* OPD is initialised to `phase(E_origin) / k0` so subsequent geometric
  trace accumulates correctly from the wave-optical state.

The new function returns the existing `RayBundle` dataclass
unchanged, so the bundle is immediately consumable by `trace`,
`spot_diagram`, `ray_fan_plot`, the JAX trace, or the HFPI / GBD
conversion helpers in `raytrace.bundles`.

## Deviations from CLUSTER_B_SPEC.md §4

Three deviations -- each because a literal reading of the spec test
text is physically unsatisfiable at the specified sampling.  All
deviations are spelt out in the test docstring + the
`from_field.py` module docstring so a future maintainer doesn't have
to reverse-engineer them.

### D1 -- `_angle_complex_gradient` uses phase-ratio, not `Im(grad E / E)`

Spec §4.4 says

```python
kx_map = np.imag(dE_dx / E_clamp)
```

(central-difference complex gradient over the clamped denominator).
This formula is *exact in the continuous limit* but, under
`np.gradient`'s central-difference discretisation, produces a biased
estimate `sin(kx*dx)/dx` for plane waves.  For the spec's tilted-plane
test (`theta = 5 deg`, `dx = 1 um`, `lam = 633 nm`, `kx*dx ~ 0.866`)
this yields `L ~ 0.0767` instead of `sin(5 deg) ~ 0.0872` -- a
relative error of 11.4 %, far outside the spec's `atol = 1e-3`.  More
seriously, central-difference *cannot* detect evanescent rays whose
`|k|` exceeds `pi/dx` because the estimator rolls back through zero;
the spec's evanescent test (`kx = 2*k0` at `dx = 1 um`) is therefore
*always* aliased back into the propagating regime regardless of the
implementation, with the central-difference form giving `|L| ~ 0.04`.

The implementation uses the *phase-ratio* central difference

```
k_x(i, j) = arg( E[i, j+1] * conj(E[i, j-1]) ) / (2 * dx)
```

instead.  This form is

* **exact for plane waves** whenever `|kx * dx| < pi`, which gets the
  `sin(theta)` test passing to machine precision under the spec's
  `atol = 1e-3`;
* **singularity-safe** (`np.angle` of a complex product is bounded in
  `(-pi, pi]` regardless of how small either factor is), so it
  handles vortex cores without the explicit clamp the spec requested;
* **a strict generalisation of `Im(grad E / E)`** in the sense that
  both reduce to `grad(phi)` in the continuous-limit Madelung
  decomposition, just with different finite-difference
  discretisations.

This is the standard "computational k-vector" used in quantum-mechanics
literature (Madelung continuity equation, Welch & Stier sub-grid
optics).  The `intensity_threshold` clamp from the spec is still
applied for the rare "both neighbouring pixels identically zero"
case (e.g. far outside a hard aperture) so the function never
returns NaN.

### D2 -- `test_evanescent_rays_marked` uses sub-Nyquist sampling

Spec §4.5 test:

```python
N = 256; dx = 1e-6; lam = 633e-9
E = np.ones((N, N), dtype=complex) * np.exp(1j * 2 * k0 * X)
```

At `dx = 1 um` and `kx = 2 * k0 = 1.986e7 rad/m`, `kx*dx = 19.86 rad`
which mod `2 pi` gives `~ 1.0 rad`.  The field is Nyquist-aliased
*before any implementation touches it*; no estimator (analytic or
discrete) can distinguish "2 k0 carrier" from "0.04 k0 carrier"
without out-of-band information.

The implementation's test uses `dx = 100 nm` (well below Nyquist for
`k0`) and `kx = 1.5 * k0`, giving `kx * dx ~ 1.49 rad < pi`.  The
phase-ratio estimator recovers `L ~ 1.5 > 1`, evanescent flagging
triggers, all 50 rays land in the evanescent bucket with
`error_code == RAY_EVANESCENT` and `N == 0`.

This is the spirit of the spec test (verify the evanescent code path
works) with sampling that physically allows the gradient to exceed
`k0`.

### D3 -- `test_opd_initialized_from_phase` uses a wrap-free slope

Spec §4.5 test:

```python
N = 128; dx = 1e-6; lam = 633e-9; k0 = 2*pi/lam
phi = 0.3 * k0 * X    # |phi| can reach 19 rad at the grid edge
E = np.exp(1j * phi)
rays = rays_from_field(E, ...)
expected = 0.3 * rays.x
assert np.allclose(rays.opd, expected, atol=lam/100)
```

At the grid edges, `|phi|` reaches `~19 rad`, far outside `(-pi, pi]`.
`np.angle(E)` returns the wrapped phase, so `rays.opd =
np.angle(E)[iy, ix] / k0` is bounded in `(-lam/2, +lam/2]`, while
`expected = 0.3 * rays.x` extends to `~ +/-12 um`.  No matter what
the OPD initialisation does, the assertion is unsatisfiable in any
region where the phase wraps.

The implementation's test computes the maximum-permitted slope
`alpha = (pi/2) / (k0 * x_max)` so the *entire* grid sits within the
principal branch (max `|phi| = pi/2`), then asserts the spec's
`atol = lam/100` against `expected = alpha * rays.x`.  This is a
strict test of the spec's stated invariant
(`opd == phase(E_origin) / k0`) on a signal where the invariant is
actually satisfiable.

## Tests

13 tests total in `tests/unit/test_v4_15_1_agent_f.py`:

**Spec-derived (7, from CLUSTER_B_SPEC.md §4.5):**

1. `test_plane_wave_normal_incidence` -- constant-amplitude,
   zero-phase field gives `(L, M, N) = (0, 0, 1)`.
2. `test_tilted_plane_wave` -- `exp(i kx X)` gives `L = sin(theta)`.
3. `test_converging_spherical_wave_focuses` -- spherical phase
   focuses to within 5 wavelengths of the axis at `z = f`.
4. `test_uniform_amplitude_uniform_density_cdf` -- rejection sampler
   on a circular aperture stays inside the support (>= 95 %).
5. `test_below_threshold_pixels_excluded` -- pixels below
   `intensity_threshold` not sampled.
6. `test_evanescent_rays_marked` -- evanescent k-vectors flagged with
   `RAY_EVANESCENT` and `alive=False` (Deviation D2 above).
7. `test_opd_initialized_from_phase` -- OPD equals
   `phase(E_origin) / k0` (Deviation D3 above).

**Additional regression (3, required by v4.15.1 brief):**

8. `test_cdf_vs_rejection_agree_on_separable_intensity` -- cdf and
   rejection placement agree on first / second moments to 5 % for a
   separable Gaussian.
9. `test_complex_gradient_handles_vortex_without_nan` --
   LG-`(0, 1)`-like field with phase singularity at origin produces
   no NaN / Inf in `x, y, L, M, N, opd`.
10. `test_random_state_reproducibility` -- integer seed reproduces the
    same bundle bit-for-bit on a second call.

**Packaging / validation (3, my additions):**

11. `test_rays_from_field_top_level_export` -- function importable
    from `lumenairy` and `lumenairy.raytrace`; in both `__all__`s.
12. `test_input_validation` -- bad shapes, non-positive `dx` / `dy`
    / `wavelength`, unknown `placement` / `angle_method`, identically
    zero field all raise `ValueError` with informative messages.
13. `test_anamorphic_dy_passes_through` -- `dy != dx` is honoured;
    ray-y coordinates extend over `dy`'s grid range.
