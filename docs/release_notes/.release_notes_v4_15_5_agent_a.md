# v4.15.5 -- Agent A release notes

Agent A scope (per dispatch): close P1-NEW-2WAY-1 (V6 walker
refactor), P1-NEW-F2-2 (`DeformableMirror.apply` direct guard),
P2-NEW-F2-4 (walker class-method descent), plus inline guards on
the highest-traffic v4.15.4-audit unguarded analyzers.

## Headline

The v4.15.4 audit (`docs/audits/AUDIT_V4_15_4_2026_05_19.md`) found
the "fix N, miss N+1" sibling-gap meta-pattern recurred AGAIN
inside v4.15.4, this time at the walker's name-prefix filter (one
indirection level higher than v4.15.4 closed it).  ~30 public
`lumenairy.__all__` functions take a 2-D `E` / `field` / `pupil` /
`object_field` / `psf` first positional but weren't matched by the
walker's `apply_*` / `propagate_*` / `richards_wolf_*` /
`debye_wolf_*` prefixes; the `DeformableMirror.apply` class method
bypassed the walker's documented class-method exclusion despite
being a direct phase-screen multiply with no delegation.

v4.15.5 closes both via the V6 meta-pin: the walker's discovery
gate switches from name-prefix to AST-based first-positional-
parameter-name matching, AND the walker now descends into class
bodies for `apply` / `propagate` methods.  The legacy name-prefix
filter is retained as a back-compat fallback so the v4.15.4
discovery surface is preserved bit-for-bit.
