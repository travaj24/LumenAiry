## Round-2 verification follow-up

**4.11.1 closes the residuals from `AUDIT_VERIFICATION_2026_05_16.md`.** An independent verification of the v4.10 / v4.11.0 fix wave identified five fixes that had landed dead-on-arrival (call-signature mistakes / wrong-API lookups), several new bugs the fix wave introduced, three unfixed JAX silent-failure paths, and one over-coarse threshold from the 4.10 Seidel-correction sign fix. 4.11.1 closes all of these and ships the first round of pinning regression tests. **All 179 unit tests pass.**

### Dead-on-arrival fixes (v4.10 series)

- **MultiWavelengthMerit chromatic optimisation** actually runs now. Pre-4.11.1 the per-wavelength wave-leg called `apply_real_lens(E, ctx.prescription, wl, dx)` positionally, but `apply_real_lens` is keyword-only after `E_in` since 4.7. Every call raised `TypeError`, silently caught by a bare `except Exception: pass`. The chromatic merit was a no-op for the entire v4.10 series. 4.11.1 passes by keyword and narrows the except to typed warnings.
- **Decentered aperture stop** is honoured. The 4.10.2 fix called `getattr(surf, 'decenter_x_m', 0.0)` on a *dict* (so always returned the default) with the wrong key names; 4.11.1 reads `surf.get('decenter')` (the actual key, value is a `(dx, dy)` tuple).
- **Circular-polarisation handedness** consistent across the three sites. The 4.10 swap of `create_circular_polarized` flipped `'right'` to `(1, -i)/√2`, which under the library's `S3 = -2 Im(Ex Ey*)` convention gives `S3 = -1` -- contradicting both the docstring ("right-hand positive") and the matching Jones vectors in `apply_waveplate` and `vector_diffraction.py`. 4.11.1 restores `(1, +i)/√2` for `'right'`.

### New bugs introduced in v4.10

- **Richards-Wolf rim mask** built from the unclipped `sin_theta = rho_p / f` before any clipping. Pre-4.11.1 the mask `sin_theta ≤ sin(theta_max)` was built AFTER `sin_theta` was clipped to `sin(theta_max)`, making the mask identically True over the whole grid -- the geometric pupil was unenforced.
- **`_sag_derivatives_param`** now has `sign(R)` (the C-RT-3 fix in 4.10 was applied only to the static `_sag_derivatives_jax` twin; the differentiable param twin was still wrong on concave surfaces).
- **`_intersect_jax_param` Newton step** uses the double-where idiom (was single-where; division was evaluated on the False branch and NaN-poisoned `jax.grad` at grazing rays).
- **`subaperture.py` output-grid unpack** simplified to `sgx, sgy = OX, OY` (was a 3-D `np.stack(..., axis=-1)` then a 2-way unpack that always raised `ValueError` for any `Ny != 2`).
- **MultiWavelength/MultiField `argmax`** is now `nanargmax` guarded by an `np.any(np.isfinite(...))` check.
- **`MultiWavelengthMerit` / `MultiFieldMerit`** honour `get_default_complex_dtype()` (were hard-coded `np.complex128`, silently negating `precision='single'`).
- **`aperture_diameter` fallback** uses an explicit `is None` test (was `or`, which silently shadowed a legitimate `0.0` sentinel).
- **MultiWavelengthMerit bare except** narrowed to `(TypeError, ValueError, RuntimeError)` and emits a `RuntimeWarning` on fallback -- the failure mode is visible now.

### Still-unfixed-despite-release-notes paths

- **`_intersect_jax`** propagates `disc < 0`, `~isfinite(t)`, and Newton-stuck states into `state.alive`. Pre-4.11.1 these silently set `t = 0` and kept the ray alive with its last-valid direction; the 4.10 release notes claimed this was fixed.
- **`_intersect_jax` and `_intersect_jax_param`** use double-where on `sqrt(maximum(disc, 0))` -- the disc=0 gradient singularity at tangent rays no longer NaN-poisons `jax.grad`.
- **`_refract` / `_reflect`** clear `rays.alive` (not only `error_code`) on direction-vector collapse. Pre-4.11.1 the dead ray continued through subsequent surfaces with its last direction, carrying a `RAY_NAN` flag that `alive`-based masks ignored.
- **`create_point_source`** central pixel is bounded by `amplitude / dx` (clamped `r` at the pixel half-diagonal instead of `1e-30` -- pre-4.11.1 the central pixel had `|E| ≈ 1e30` and dominated every integrated power calculation).

### Dormant fix activated

- **GBD through-prescription** populates `axial_opl = sum_k n_k * thickness_k` over each segment via `surfaces_from_prescription` + `get_glass_index`. The `apply_abcd_to_beamlets` `axial_opl=` kwarg has been accepted since 4.10.2 but `propagate_gbd_through_prescription` never populated it; the reconstructed field now carries the system's absolute axial phase reference.

### Threshold / docstring follow-ups

- **Seidel-correction RMS gate** in `apply_real_lens` dropped from 50 nm to 5 nm. The 50 nm threshold was set when the 4.10 sign bug routinely produced corrections of O(λ); after the sign fix real residuals collapsed to a few-nm range and the gate was silently skipping every meaningful correction.
- **RS docstring** updated to show the corrected Goodman 3-43 `(1/r - ik)` form (was showing the pre-4.10 `(ik - 1/r)` form -- the code was correct but the docstring lagged).
- **`seidel_wfe` docstring** shows `H²·ρ²` (Lagrange invariant) instead of `σ²·ρ²` -- matches the code's actual computation, with a one-paragraph note on the relationship.
- **`_transfer_jax` accuracy bound** updated from "~1% for NA ≤ 0.1" to "~0.5% per surface, accumulates" with the explicit per-surface scaling.
