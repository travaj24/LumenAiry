### Performance — implementation

- **pyFFTW double-buffer plan cache + auto-promote `FFTW_ESTIMATE → FFTW_MEASURE`** at the 5th call per `(direction, shape, dtype, threads)` key. Saves 256 MB–1 GB allocation per call on large complex128 grids. `set_fft_auto_promote(False)` disables for startup-sensitive workflows.
- **`through_focus_scan` (NumPy) H-hoist** — input FFT, kx/ky, propagating mask, target-dtype all hoisted outside the z-loop. Bit-near-exact (abs err 0.0) vs per-z reference.
- **`zernike_basis_matrix` content-fingerprint cache** — every Zernike merit in a CompositeMerit eval and every FD Jacobian column hits the cache. `clear_zernike_basis_cache()` exposed.
- **JAX jit caches** at `propagate_through_system_jax`, `gerchberg_saxton_jax` / `error_reduction_jax` / `hybrid_input_output_jax`, and the inner ASM kernel inside `through_focus_scan_jax`. Module-scope `OrderedDict` caches keyed on element-chain signature or `n_iter`.
- **`propagate_modal_asymptotic` `lg_polynomial` hoist + `lru_cache`** — moves the LG-polynomial build outside the per-pixel Newton loop; per-pixel work drops from `N_pixels × N_modes` to `N_modes` recomputes.
- **`propagate_hf_chebyshev_quadrature` chunk vectorisation** — replaces scalar pixel loop with `np.einsum('cyx,yx->c', kernel, E_in)`. New `max_chunk_memory_mb=256.0` kwarg caps peak alloc. Fixes a pre-existing latent shape-mismatch bug along the way.

### Round-4 audit — ~20 PyPI release blockers fixed

**Tier 0 (user-facing showstoppers)**:
- **README cookbook examples** — 11 broken code blocks fixed (positional `apply_real_lens` calls converted to keyword; `create_gaussian_beam` missing `wavelength` added; renamed `load_zmx_prescription` updated).
- **`_deprecation.py` shims wired** for `load_zmx_prescription → load_zemax_zmx` and `load_zemax_prescription_txt → load_zemax_prescription_data_txt`. Old-name calls emit `DeprecationWarning` and forward to the new function.
- **`gerchberg_saxton(backend='jax')` forwards `seed`/`dtype`/`initial_phase`** end-to-end (function-level kwargs were already wired internally; the unified dispatcher just didn't forward them).

**Tier 1 (silently-wrong physics in default paths)**:
- **JAX/NumPy aperture schema unified** — `propagate_through_system_jax` accepts canonical NumPy schema (`diameter`, `width_x/y`, `inner_diameter/outer_diameter`) AND legacy `radius`/`half_width_*`/`inner_radius` with `DeprecationWarning`.
- **`propagate_through_system_jax` fail-fast** on non-traceable elements — `NotImplementedError` lists offending types before any tracing. `_TRACEABLE_ELEMENT_TYPES = frozenset({'propagate', 'lens', 'aperture', 'mask'})` exposed.
- **Rayleigh-Sommerfeld `z≤0` guard** — matches existing Fresnel/Fraunhofer/SAS forward-only guards.
- **ASM-MFT band-limit `<=` → `<` on NumPy** — matches the JAX branch (one-bin boundary disagreement fixed).
- **SAS pad>2 centring** — `as1 = (N_new - N) // 2` (was `(N+1)//2`, only correct for pad=2).
- **Dispatcher negative-z routing** — `_auto_select_method` short-circuits to ASM for `z<0`; explicit forward-only method with `z<0` raises a dispatcher-level `ValueError` naming `propagate`.
- **`propagate(return_result=True)` tuple unpacking** — Fresnel/Fraunhofer/SAS/Fresnel-MFT now report the kernel's output `dx`, not the input `dx`.
- **Dispatcher `output_grid`/`output_dx` for ASM family** — auto-promotes to MFT variants; SAS/RS raise with guidance.
- **`_apply_doe_kick_jax` gradient flow** — `jnp.where`-based dispatch preserves `jax.grad` through grating period.
- **`makedammann2d` no longer mutates global `np.random` state** — switched to `np.random.default_rng(seed)`.

**Tier 2 (silently-wrong physics in non-default paths)**:
- **`image_plane_wfe` reference-sphere radius includes `1/N_chief`** for off-axis fields.
- **`distortion_grid` `L²+M²<1` guard** — raises `ValueError` for fields that would produce N=0 rays.
- **`apply_real_lens_traced` mirror guard** — pre-flight scan raises a properly-named error pointing at the per-segment `apply_mirror` pattern for folded designs.
- **`ghost.py` docstrings** clarify `'intensity'` is an UPPER BOUND (ignores transmission losses; correction formula provided) and `'focus_z_estimate'` is a heuristic harmonic-mean sort key.

### Deferred to v4.12.1

Three items deferred — their pinned isolated tests passed but the cross-suite validation caught regressions:

- **Raytrace Newton spherical fast-path + analytic-normal stash** — caused a 1.17e-3 NumPy↔JAX drift in `aberration_tensor_lg00_jax`. Per-ray bit-near-exact pin held, but cumulative drift in downstream Maslov asymptotic exceeded the cross-backend tolerance.
- **`trace_jax` flat-tuple jit cache** — broke `jax.grad(fit_canonical_polynomials_jax)` (returned NaN). v4.12.1 will revisit with pytree-registered prescription wrapper.
- **B1-10 half-pixel grid convention drift** between propagator families. ASM/Fresnel/RS/sources use `(arange(N) - N/2) * dx`; GBD/HF/subaperture/MHS/`optimize/core.py` use `(arange(N) - N/2 + 0.5) * dx`. Cross-method coherent superposition has a half-pixel shift producing wrong-physics phase error ~`k₀·dx/2·off-axis distance`. Tier-2 finding; per-site refactor scheduled.
